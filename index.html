03 / Architecture

Clear layers. Clear responsibilities.

Requests move through the controller and service layers to repository interfaces, with Spring Data JPA/Hibernate handling database access.

Client / PostmanHTTP request
ControllerREST endpoints
ServiceBusiness contract
ServiceImplBusiness logic
Repository → MySQLJPA / Hibernate

DTOs and MapStruct separate API payloads from persistence entities. Supporting features include security, validation, exception handling, caching, auditing, and logging.
