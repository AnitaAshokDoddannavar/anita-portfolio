# CampusConnect Portfolio Website

A responsive, single-page portfolio for Anita Ashok Doddannavar featuring the CampusConnect Student Placement Management System.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. No build tools or external libraries are required.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `anita-portfolio`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the published URL shown by GitHub Pages after deployment completes.

## Before publishing
- Replace the generic `mailto:` link with your preferred professional email address.
- Add your LinkedIn profile and resume link if you want them public.
- Verify the repository is public and the project description matches your current code.
- The portfolio describes a backend REST API; it does not claim a separate frontend or live hosted demo.

## Included
Responsive dark navy/blue design, project overview, skills, architecture, placement workflow, engineering practices, mobile navigation, and GitHub links.
